# Contributing

1. Fork the repository and branch from `main`.
2. Use fictional names and data in tests, docs, and screenshots.
3. Run PHP lint and every shell smoke test listed in `AGENTS.md`.
4. Describe behavior changes and manual UI checks in the pull request.
5. Never include live family data, photos, addresses, tokens, or signing material.

Small, focused pull requests are easiest to review. Changes to the API contract should update the README and `docs/ARCHITECTURE.md`.
